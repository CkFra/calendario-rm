# Calendario del Real Madrid

Calendario `.ics` con los partidos del Real Madrid, actualizado solo cada 6 horas con GitHub Actions y publicado con GitHub Pages.

- **Suscribirse:** `https://ckfra.github.io/calendario-rm/realmadrid.ics`
- **Fuente:** [football-data.org](https://www.football-data.org) (plan gratuito: LaLiga y Champions).
- **Token:** secreto `FOOTBALL_DATA_TOKEN` del repo.
- **Lanzarlo a mano:** pestaña *Actions* → *Actualizar calendario* → *Run workflow*.

Los partidos con fecha pero sin hora confirmada salen como evento de día completo «(hora por confirmar)».
